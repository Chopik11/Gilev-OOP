# Аптека — учёт медикаментов

Windows Forms приложение на C# (.NET Framework 4.7.2) + SQLite.

## Структура проекта

```
Pharmacy/
├── Pharmacy.csproj          # Файл проекта Visual Studio
├── Program.cs               # Точка входа
├── DB/
│   └── DatabaseHelper.cs    # ADO.NET + SQLite, инициализация БД
└── Forms/
    ├── MainForm.cs           # Главная форма (навигация)
    ├── MedicinesControl.cs   # Модуль «Лекарства»
    └── SalesControl.cs       # Модуль «Продажи»
```

## Быстрый старт

### 1. Открыть проект
Откройте `Pharmacy.csproj` в Visual Studio 2019 / 2022.

### 2. Установить пакет SQLite
В Package Manager Console:
```
Install-Package System.Data.SQLite
```

### 3. Собрать и запустить
`Ctrl+F5` — база данных `pharmacy.db` создаётся автоматически при первом запуске рядом с `.exe`.

## Функциональность

### Модуль «Лекарства»
| Функция | Описание |
|---------|----------|
| Просмотр | Таблица со всеми лекарствами (категория, цена, остаток, срок) |
| Добавление | Заполните поля → «Добавить» |
| Редактирование | Выберите строку → измените поля → «Сохранить изменения» |
| Удаление | Выберите строку → «Удалить» |
| Поиск | Реалтайм-фильтр по названию |
| Сроки годности | Красный = просрочено; жёлтый = менее 7 дней до истечения |

### Модуль «Продажи»
| Функция | Описание |
|---------|----------|
| Корзина | Выберите лекарство + количество → «В корзину» |
| Удаление позиции | Выберите строку корзины → «Удалить позицию» |
| Оформление | «Оформить продажу» — списывает остаток, записывает в БД |
| История | Правая панель — последние 50 продаж |

---

## База данных

Файл `pharmacy.db` (SQLite) создаётся автоматически. При первом запуске заполняется демо-данными: 5 категорий и 8 лекарств.

### Таблицы

| Таблица | Ключевые поля |
|---------|--------------|
| `Categories` | id, name |
| `Medicines` | id, name, category_id, price, stock, expiry_date |
| `Sales` | id, date, total |
| `SaleItems` | id, sale_id, medicine_id, quantity, price |

## Технологии

- **C# / .NET Framework 4.7.2**
- **Windows Forms** — интерфейс
- **SQLite** через `System.Data.SQLite` (ADO.NET)
